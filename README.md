# داشبورد آفلاین آدیت فروشگاه‌ها

این مخزن یک داشبورد مستقل HTML برای نمایش آدیت دوره‌ای فروشگاه‌هاست. برای مشاهده آخرین خروجی، فایل `index.html` را باز کنید.

## ساخت خروجی جدید

1. از فایل `قالب ورود اطلاعات آدیت.xlsx` یک کپی بگیرید.
2. هدرهای نام فروشگاه، ماه و سال را داخل اکسل تکمیل کنید.
3. برای تمام ۵۵ شاخص امتیاز صفر یا یک وارد کنید.
4. فایل تکمیل‌شده را داخل پوشه `data` قرار دهید. نام فایل دلخواه است و در تشخیص فروشگاه یا دوره نقشی ندارد.
5. روی `ساخت داشبورد.bat` دوبار کلیک کنید.
6. فایل‌های `dashboard.html` و `index.html` براساس محتوای پوشه `data` از نو ساخته می‌شوند.

برای حذف یک دوره، فایل اکسل مربوط به آن را از پوشه `data` بردارید و مولد را دوباره اجرا کنید.
